# Glitch Rabbit — 关键像素精灵

[English](README.md) · 简体中文

2026-09-23 定稿的关键资产：宠物页面角色的站立正面基础帧，64×64。画风对齐角色官方
2D 设定（薰衣草紫身体、珊瑚红背带裤、圆顶眼的奶油黄楔形、满排方块牙、统一深棕描边）。
风格参考图仅在此描述，**不入库**。

## 文件

- `base-64.png` — 定稿基础帧（64×64 RGBA，11 色）。
- `gen_sprite.py` — 参数化生成脚本，产出 `base-64.png`（以及供审阅的
  `preview_4x.png`、`face_zoom_6x.png`）。后续所有动作帧必须从本脚本派生，
  以保证五官画法和调色板一致。

## 硬性约束（设备端契约）

- 必须是 **64×64** RGBA PNG、实色透明（其他尺寸会被门户和管线拒绝，
  见 `service/src/assets/pipeline.ts`）。
- **双脚必须画在画布最底一行**：设备端把精灵底边锚定到地面线并按 2×
  最近邻放大渲染（`main/ui/ui_pet.c` 的 `PET_SCALE`），任何动作的任何帧
  脚底不在底行就会浮空或入地。
- 时段外观和天气由运行时染色与叠加精灵实现——不要把变体烘焙进动作帧
  （规格 §5.1）。

## 帧数规则（服务端强校验）

run/fight 4–8 帧，sleep 2–4 帧，victory 1–4 帧，每个动作 1–10 fps。帧序列
通过配置门户上传 PNG、服务端转码为 RGB565A8；或烘焙进
`main/assets_default/` 的默认 bundle 用于出厂镜像。

## 重新生成

```bash
python3 gen_sprite.py
```
