## 已确定的产品方案

NFC 轻碰应进入**一个明确的入口**，按两个阶段引导：先连接并配对设备，再管理名牌、账户、素材、偏好和设备。配网页由设备 SoftAP 托管，日常配置中心由本地服务托管。手机在接入过程中会切换网络，因此它们无法始终是同一个 HTTP 页面；两阶段应保持一致的文案和视觉层级，配网成功且服务可达时再引导进入配置中心。设备设置入口和手机浏览器的手动路径必须始终可用。

主屏同一张卡展示姓名、可选身份和今日 Token；按 OK 仍进入用量明细。步行宠物位于地图左侧，右侧展示三个**已完成**番茄读数：今日、累计、距下次升级还需。地图下方五圆点只表示**本次计时**，不表示历史累计。当前主屏的权威布局与渲染见[主屏设计](2026-09-24-home-panel-redesign.zh_CN.md)及 `main/ui/ui_pet.c`。

## 剩余工作：建议顺序

1. **新版主屏与同步反馈真机验收。** 下述准确镜像已于 2026-09-24 写入应用分区并通过设备端哈希校验。仍需检查名牌、三个番茄值、底部操作、设置反馈、唤醒和导航。随后配对到可达的本地服务，验证后台保存名牌后手动同步能显示新值。屏幕和完整同步路径仍待用户反馈。
2. **统一接入流程。** 设备配网页补齐连接、配对、错误、重试状态；手机能访问服务时引导进入配置中心。保留设备设置的手动入口。测试 Wi-Fi 错误、服务不可达、配对码过期、重新连接，以及系统未弹出配网页。
3. **用目标手机验证 NFC。** 硬件有被动 NTAG213，支持普通 NDEF 读写，没有 MCU 侧 BSP API。仓库尚无 NFC 内容写入、轻碰处理或已验证的手机路径。需先用真实手机和网络切换过程验证，再决定稳定入口 URL 或记录格式；不能承诺所有手机一次轻碰就同时连 Wi-Fi、打开后台。系统无法自动完成时给出明确的手动步骤。
4. **完善日常配置中心。** 在保留现有鉴权和表单行为的前提下，把名牌／账户／偏好／设备／素材页推进到统一视觉，并增加真实连接状态和预览。总览页与动画预览仍属后续工作。

NFC 接入验收标准：从未配对设备出发，轻碰或手动回退能看到连接指引；手机可加入 SoftAP、提交四项表单、看到配对结果、回到局域网并进入有鉴权的服务配置中心。每一种目标手机／系统都需重复验证。NFC 记录不得含 Wi-Fi 密码、API Key、后台口令、配对码或设备令牌。
