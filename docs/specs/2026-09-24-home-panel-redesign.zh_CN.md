# 主屏重设计（Home Panel Redesign）规格

- 日期：2026-09-24
- 状态：视觉设计已接受并实现；待真机验收
- 交付对象：UI 设计师（功能点与交互约束）／固件工程（实施依据）
- 术语：见 [`docs/CONTEXT.zh_CN.md`](../CONTEXT.zh_CN.md)
- 取代：[多合一挂坠规格](./2026-09-22-multi-pendant-app.zh_CN.md) §3（页面与导航）与 §7.1（设置页交互模型）；该规格其余章节继续有效，冲突处以本文为准

## 1. 背景与目标

三个一级页循环导航在实测中导致迷失：仪表盘与设置两个一级页自身不承载核心信息，只是下钻入口与切页走廊。本次重设计移除该发射层，收敛为**单主屏 + 二级列表**的单栈模型：

- 主屏唯一，宠物场景常驻，开机直达；
- 数据与设置经主屏光标进入各自二级列表；
- 任何二级／三级界面长按 OK 逐级返回，最终回到主屏；
- 息屏唤醒永远回主屏。

北极星不变：**活的挂坠**——宠物是人格化外壳，数据是它的情绪来源，番茄计时是它的日常。主屏静息状态展示"宠物 + 本日消耗头条"，不按键即可获得两个最高频读数。

## 2. 信息架构

```
主屏（唯一一级；开机直达；唤醒回此）
 ├─ 头条：本日 Token 消耗（大数字）
 ├─ 光标靶标（UP/DOWN 移动，首尾环绕）：
 │    ① 头条本身      ② 番茄指示条（5 圆点）      ③ 设置图标
 │    ① OK ─▶ 用量页（二级）
 │    ② OK ─▶ 番茄数调整（主屏内嵌状态）
 │    ③ OK ─▶ 设置列表（二级）
 └─ 宠物场景常驻（动作/地图/天气/时段，沿用旧规格 §5）

用量页（二级）──OK──▶ 下钻详情（三级）── 长按逐级返回
设置列表（二级）──OK──▶ 调整态 / 流程页（三级）── 长按逐级返回
```

## 4. 番茄设置流（主屏内嵌状态机）

原则：指示条承载一个数量设置 `n ∈ 0..5`；OK 确认即"读取 n → 以 n×25 分钟为总时长重新倒计时"。**设置过程中，任何运行中的倒计时不随之变动。**

```
IDLE ──OK（指示条）──▶ ADJUST（初始 n = 上次设置，无则 1）
ADJUST：UP/DOWN ─ n±1，夹在 0..5；到 5 再加 = 短促提示音，不变
         n=0 时界面呈"取消"语义
ADJUST ──OK──▶ n≥1：RUNNING（自此刻起倒计时 n×25min，重新计）
                n=0：IDLE（取消全部计时，不授经验）
ADJUST ──长按OK──▶ IDLE（放弃本次修改；运行中的计时不受影响）
RUNNING ──OK（指示条）──▶ ADJUST（初始 n = 本次运行单元数）
RUNNING ──单元边界（每满 25min）──▶ 静默 +1 经验（已授数持久化）
RUNNING ──全部结束──▶ VICTORY（动画+音效，自动跳主屏）──▶ IDLE
```

- 每次确认都是**全量重读**：运行中改 n=4 并确认，总时长变为 4×25min、自确认时刻起算（进度重开）。此语义为产品明确选择；误确认会丢弃已跑进度，ADJUST 界面须有"确认后将重新开始"的明示位（OQ5）。
- 已授经验永不回收；取消不授经验。
- 掉电持久化沿用旧规格 §6.1：绝对结束时间戳、n、已授经验数写 NVS，重启按绝对时间重算。
- 计时中浅睡／空闲深睡（ADR-0003）不变。
- 取消全部计时的唯一入口 = ADJUST 中减到 0 再确认（OQ2 含备选方案）。

## 5. 用量页（二级，复用现仪表盘实现）

- 进入：主屏头条靶标 OK；长按 OK 返回主屏。
- 内容：现三卡（周额度／5 小时额度／本周 Token，主力账户口径）原样复用；卡片选中态、OK 下钻、下钻页（三级）现实现保留，仅长按返回目标从"仪表盘主界面"改为"用量页→（再长按）主屏"。
- UP/DOWN 从"切换一级页"改为"三卡间移动光标"。
- 快照 schema 需新增本日聚合字段（§8），为 P1 必需——它是头条的数据来源，与仪表盘页自身的横向扩展无关。
- 已知口径差异（OQ6，暂不调和）：头条为"本日 · 全账户求和"，页内三卡为"周 · 主力账户"。仪表盘页后续扩展（增加本日行等）另立需求。

## 6. 设置列表（二级，复用现实现）

- 进入：主屏设置图标 OK；长按 OK 返回主屏。
- 行项不变：亮度／Wi-Fi（配网）／自动息屏／作息时间／连接手机／音量／立即同步。
- 交互沿用旧规格 §7.1 分层，仅一处改动——所有"长按退回一级页"改为"长按返回主屏"：
  - 列表：UP/DOWN 移光标；OK 选中；长按返回主屏。
  - 调整态（亮度／音量／自动息屏）：UP/DOWN 实时调值；OK 确认回列表；长按取消并恢复进入值。
  - 流程页（配网／作息／连接手机）：键位以页内底部提示栏为准；长按逐级返回。
  - "立即同步"为即时动作：OK 触发并停留在列表。
- 番茄胜利自动跳主屏时，若用户正在某调整态中：按"长按取消"语义**恢复进入值**后跳转（OQ3）。

## 8. 头条数据口径与格式化

- 口径：**全部已连接 Coding 账户**自本地零点起的 Token 消耗总和（非主力账户口径）。由本地服务聚合、随快照下发，设备只渲染。
- schema：快照新增 `dailyTokens`（形态见 OQ7，推荐顶层聚合字段，如 `"dailyTokens": { "used": 832000 }`）。离线沿用最后已知值，数据新鲜度由状态条同步年龄标注。刷新节奏 = 快照节奏（每小时 + 手动同步），非实时。
- 格式化规则（纯逻辑函数，主机侧单测覆盖）：
  - 值 < 1000：原样整数，无单位（`832`）；
  - 否则取 4 位有效数字，**向下截断（不舍入）**；单位 K/M/B/T 按 1e3/1e6/1e9/1e12 进位，取值 ≥1 的最大单位；
  - 示例：832,000→`832.0K`；1,234,567→`1.234M`；1,999,999→`1.999M`；12,345,678→`12.34M`；123,456,789→`123.4M`；1,234,567,890→`1.234B`；1.5e13→`15.00T`；
  - 上限：值 ≥ 1e16 时封顶显示 `9999T`。

## 9. 设计师约束与必备元素

- 画布 240×320（RGB565），输入仅三键（UP/DOWN/OK，OK 支持长按），无触屏。
- 中文 UI：新增文案进入字体子集预算（每字形有 Flash 成本），文案精简。
- 主屏必备元素清单（不可缺）：状态条、本日消耗头条、Lv 徽标+进度条、时钟、宠物场景（240×160 地图条带）、番茄指示条（5 圆点）、设置图标、光标视觉。
- 控件数红线：无 PSRAM，主屏控件数固定且少；页面切换即建即毁的内存模型不变。装饰性控件需逐一过内存账。
- 需要设计产出的形态：光标选中态、三靶标布局与设置图标形态、ADJUST 界面（含"确认后重新开始"明示文案位）、二级列表视觉（行高/字号/选中态）、下钻页视觉。

## 14. 当前实现检查点

真机结果。当前源码在同一张可选卡中显示姓名／身份与今日 Token，`PET_X=84`，
地图固定读数来自持久化的 `today_count`、`total_xp` 及
`app_xp_to_next(total_xp)`。“立即同步”可区分未配对、未联网、请求／进行中、
