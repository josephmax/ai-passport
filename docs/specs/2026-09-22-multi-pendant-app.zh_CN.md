# 多合一挂坠应用（Multi-Pendant）开发规格

- 日期：2026-09-22
- 状态：现有应用部分已实现；BLE 固件／macOS 伴侣已实现，设备验收待完成
- 2026-09-24：§3（页面与导航）与 §7.1（设置页交互模型补充定稿）已被[主屏重设计规格](./2026-09-24-home-panel-redesign.zh_CN.md)取代；其余章节继续有效，冲突处以新规格为准
- 2026-10-14：[BLE 伴侣 MVP](2026-10-14-ble-companion-mvp.zh_CN.md) 取代设备联网、手机接入、每小时 HTTP 下发和本地 ASR 提案。本次更新的是目标，当前固件仍用 Wi-Fi／HTTP，BLE 关闭。推翻记录：[ADR 0006](../adr/0006-ble-companion-without-device-networking.zh_CN.md)、[ADR 0007](../adr/0007-microphone-bridge-reuses-desktop-dictation.zh_CN.md)。
- 术语：见仓库根 [`CONTEXT.md`](../CONTEXT.md)；关键决策见 [`docs/adr/`](../adr/)
- 目标平台：FoloToy AI Passport（ESP32-C3，8MB Flash，无 PSRAM，240×320 ST7789P3，UP/DOWN/OK 三键，ES8311 音频，无震动马达）

## 1. 概述

单一固件采用单主屏和二级用量／设置页，保留带经验／天气的宠物番茄计时，并增加明确的麦克风模式。本地服务负责采集、配置、素材转码和天气；附近电脑伴侣通过 BLE 与设备交换快照和麦克风音频。挂坠不入网，电脑保持自己的互联网连接。麦克风成为桌面音频输入，由用户现有的 Typeless 负责识别／整理／文字输入。

产品北极星：**"活的挂坠"**——宠物是人格化外壳，数据是它的情绪来源，番茄钟是它的日常。

## 2. 系统架构

### 2.1 下一版已接受架构（2026-10-14；待实现）

```text
主机浏览器 -> 本地服务（采集器、快照、设置、PNG/APB1）
                     | 鉴权回环访问
                     v
                Mac 伴侣 <--- BLE PCM/状态 --- 挂坠
                     |   --- BLE 快照/时间 --> 挂坠
                     v
              虚拟麦克风 -> Typeless -> 当前文本框
                                | 云端识别/整理
```

厂商凭证仍在主机。设备持久化电脑绑定、本地设置、番茄／经验、最后快照及当前素材，新流程不要求 Wi-Fi 凭证或服务地址。BLE 配对、音频流、迁移保留和 M0–M3 关卡以 [BLE 伴侣规格](2026-10-14-ble-companion-mvp.zh_CN.md) 为准。BLE 素材传输延后，当前素材继续可用。

## 3. 页面与导航

三个一级页循环切换。**键位表（定稿）**：

| 位置 | UP/DOWN 短按 | OK 短按 | OK 长按 |
| --- | --- | --- | --- |
| 仪表盘主界面 | 切换一级页 | 下钻选中项 → 进入详情 | 无 |
| 仪表盘下钻页 | 在三项详情间切换 | — | 返回主界面 |
| 宠物页 | 切换一级页 | 启动/累加番茄计时 | 取消全部计时 |
| 设置页 | 切换一级页 | 进入/调整选项 | 返回/退出选项 |

息屏唤醒后回到息屏前所在页。番茄胜利时无论当前在哪页，自动跳到宠物页播胜利动画+音效后停留。

## 4. 仪表盘

### 4.1 主界面

四张紧凑汇总卡；前三张数据来自**主力账户**（配置中心可选，默认本地 Agent）：

1. **周额度**：百分比大字 + 用量/上限小字 + 重置倒计时（天）
2. **5 小时额度**：百分比 + 当前窗口剩余时间
3. **本周 Token 消耗**：百分比（分母=配置中心设置的周 Token 预算，未设置则显示纯数值）
4. **Agents**：有本地日志读数的 Agent 来源数

卡片选中态高亮，OK 下钻。顶部状态条：同步时间（`xx分钟前`）、电脑／BLE 连接状态、电池。采集新鲜度与连接状态分开。

### 4.2 下钻页

UP/DOWN 在一级页切换四张卡。前三项详情展示主力账户该维度的数值，以及其他账户同维度列表。Agents 详情每次展示一个本地来源的今日／本周 Token、5 小时／周额度，UP/DOWN 切换来源。长按 OK 返回卡片页。

### 4.3 用量快照（服务 → 设备）

## 5. 宠物

### 5.1 动作与渲染

| 动作 | 触发 | 帧规格 |
| --- | --- | --- |
| 跑步 | 默认态 | 64×64，4–8 帧循环 |
| 打怪 | 番茄计时进行中 | 64×64，4–8 帧循环 |
| 睡觉 | 作息窗口内且无计时 | 64×64，2–4 帧循环 |
| 胜利 | 计时全部结束 | 64×64，一次性播放 1–2s |

地图条带：宽 240 × 高 160，横向匀速滚动、首尾无缝循环；角色固定 x≈屏 1/3，贴地。时段效果用**运行时调色**实现（白天原色 / 傍晚暖色 / 夜间压暗偏蓝，LUT 或 LVGL 样式），天气用小尺寸叠加精灵（雨丝/雪花各 1 组 2–3 帧动画、晴天光斑、阴天无叠加）——**不预烘 12 套地图**。

### 5.2 天气矩阵（4 天气 × 3 时段）

时段由快照内当日日出日落划分：白天=sunrise+30min ~ sunset−60min，傍晚=sunset−60min ~ sunset+45min，其余为夜间（阈值两端留余量，避免闪烁切换，加 10 分钟滞回）。天气由 WMO code 归一化：0–2 晴，3/45/48 阴，51–67/80–82 雨，71–77/85–86 雪。离线沿用最后已知。

### 5.3 头顶 HUD 与底部信息条

- 顶部：`Lv.12` 徽标 + 当前级内进度细条（宽 80px）
- 底部信息条（三项，用户指定）：`今 3 · 周 18 · 下一级 7`（单位番茄）

### 5.4 作息

默认 23:00–次日 8:00 睡觉（停止跑步动画、显示睡觉动作、地图停止滚动），**设备设置页可调**起止时间（±分钟步进 30）。作息窗口内仍允许开番茄钟（宠物熬夜打怪），胜利音效音量跟随设置。

## 6. 番茄计时与经验

### 6.1 状态机

```
IDLE ──OK短按──▶ RUNNING(单元数n=1)
RUNNING ──OK短按且n<5──▶ RUNNING(n+1)      // 每按一次 +25min
RUNNING ──OK短按且n=5──▶ 短促提示音,不变
RUNNING ──OK长按──▶ IDLE(取消,不记经验)
RUNNING ──到时──▶ VICTORY(动画+音效,授经验n) ──▶ IDLE
```

- 计时进行中允许息屏/浅睡（ADR-0003）：状态（绝对结束时间戳、单元数、已授经验数）每次变更写 NVS，掉电重启后按绝对时间重算
- 单元边界（每满 25 分钟）静默 +1 经验；全部结束才播胜利
- 胜利时若在其他页自动跳转宠物页

### 6.2 经验与等级（分段定值，单位=番茄）

| 当前等级 L | 升到 L+1 需（番茄） | 节奏参考（8 番茄/天） |
| --- | --- | --- |
| 1–9 | 5 | 一天升 1.6 级 |
| 10–29 | 15 | 约 2 天 1 级 |
| 30–59 | 25 | 约 3 天 1 级 |
| 60–98 | 50 | 约 6–7 天 1 级 |
| 99 | 100（终局） | 约 12 天 |

满级 100 = 累计 3145 番茄 ≈ 1308 小时专注。等级=分段表反查，纯整数运算；`今日番茄`/`本周番茄`分别于本地 0 点、周一 0 点清零；经验与等级永不清零。全部存 NVS。

### 7.1 设置页交互模型(补充定稿)

设置页采用严格分层,一级键位不产生歧义:

- **一级**:只有一个大"设置"按钮。上/下切换一级页;OK 进入列表;长按无操作。
- **二级(列表)**:上/下移动光标;OK 选中高亮项;长按退回一级。
- **调整态**(数值项:亮度/音量/自动息屏):OK 选中后进入。上/下调整数值
  (实时生效);OK 确认并回列表;长按取消并恢复进入时的值。
- **流程页**(绑定、麦克风与多字段作息项):选中后进入下一级
  界面,键位以底部提示栏为准;长按逐级返回。
- "立即同步"为即时动作:OK 触发并停留在列表。

## 8. 设备 ↔ 服务协议

- 下一版传输：一条认证 BLE GATT 连接，包含版本化控制、快照和音频消息；设备不请求 HTTP 端点，不配置 IP。
- 同步：绑定／重连、主机成功刷新或配置变更后推送；手动“立即同步”请求伴侣下发。主机采集独立调度，不再等待设备每小时拉取。
- 载荷：保留 §4.3 快照和 4096 字节上限，完整接收、校验、确认后应用；部分下发保留最后有效数据，分别标识过期与连接断开。
- 时间：主机下发时新生成 `servedAt`，`generatedAt` 保留采集时间；继续兼容旧快照解析。
- 音频：明确麦克风模式中的设备 → 主机 PCM notification；控制／停止优先，其次音频，快照合并并延后至采集停止再持久化应用。
- 素材：MVP 保留内置／已安装素材。后续 APB1 用 BLE 分块、校验后原子写 LittleFS，不使用旧 HTTP 下载；不支持的素材更新不得阻塞快照。

原 `POST /api/pair`、`GET /api/snapshot` 和 `/assets/*` 请求仍在当前旧实现中，是历史传输契约，不是下一版目标。完整消息语义与验收见 [BLE 伴侣规格](2026-10-14-ble-companion-mvp.zh_CN.md)。

## 11. 内存与电源预算（红线）

- 下一版设备无 Wi-Fi／TLS 栈。须更改当前关闭 BLE 的配置，并实测堆、DMA、最大连续块及任务栈，不能直接叠加历史 Wi-Fi／BLE 估值。
- 2026-10-16 BLE 启动修复后，LVGL 池为 48 KiB，主屏常驻；原生渲染压力测试峰值为 36.5 KiB。这不代表 ESP32 的堆／任务栈实测，见 [启动修复检查点](2026-10-14-ble-companion-mvp.zh_CN.md#10-2026-10-16-启动失败与修复)。不能把旧语音报告的 24 KiB 估值当成现状。
- 音频使用有界流队列，设备 PCM 暂定最多 16 KiB；不存整句或录音文件。采集中冻结动画、延后快照持久化／素材。
- 采集独占 codec，先停止音效并确认，再采集；持续传输阻止自动休眠。番茄／经验继续，胜利音效／导航等到采集停止。
- 后续素材分块写入，不整包进 RAM。活动麦克风模式外保留既有电源不变量。板级休眠／传输电流及续航须实测，芯片级微安数字不能作为产品承诺。

## 12. 测试与验收

主机侧单测（纯逻辑，不碰硬件）：番茄状态机（堆叠/取消/掉电重算/跨单元授经验）、分段经验表与今日/本周重置、天气归一化与时段滞回、快照解析与离线标注。

## 14. 风险与待确认假设

1. **ChatGPT 订阅额度采集无官方接口**（P2，可能降级为 API 用量口径或砍掉）
2. **GLM Coding Plan 额度口径**需在服务端调研确认（有无官方/可推导口径）
3. **UI 语言默认中文**——需内嵌字体子集（约 100–200KB Flash，已计入 3MB 固件预算）；如要英文可零成本切换，**此项待你最终确认**
4. ccusage 类开源方案随 Claude Code 本地格式演进可能失效，采集器插件化隔离影响
5. 深睡期间 RTC 漂移：靠每次同步对时纠偏，长期离线时作息窗口可能偏移（可接受）
