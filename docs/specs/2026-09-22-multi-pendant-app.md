# 多合一挂坠应用（Multi-Pendant）开发规格

- 日期：2026-09-22
- 状态：需求已确认，待实施
- 术语：见仓库根 [`CONTEXT.md`](../../CONTEXT.md)；关键决策见 [`docs/adr/`](../adr/)
- 目标平台：FoloToy AI Passport（ESP32-C3，8MB Flash，无 PSRAM，240×320 ST7789P3，UP/DOWN/OK 三键，ES8311 音频，无震动马达）

## 1. 概述

单一固件包含三个一级页：**仪表盘**（Coding 账户额度监控）、**宠物**（以宠物为外壳的番茄钟，带经验等级与天气）、**设置**。配一个跑在用户本机的**本地服务**：采集各家账户用量（复用开源方案）、托管 Web 配置中心、转码并分发宠物素材、转发天气。设备入网后每小时向本地服务拉取一次快照。

产品北极星：**"活的挂坠"**——宠物是人格化外壳，数据是它的情绪来源，番茄钟是它的日常。

## 2. 系统架构

```
┌─ 手机浏览器 ──── 配置中心(Web, 本地服务托管)
│                    │ 账户连接/素材上传PNG/城市设置/主力账户选择
│                    ▼
│              ┌─ 本地服务 ─────────────────────┐
│              │ 采集器插件 × N（开源方案）      │
│              │  ├ Claude: 读 Claude Code 日志  │
│              │  ├ GLM/DeepSeek: 官方余额 API   │
│              │  └ ChatGPT: 待调研(P2)          │
│              │ 快照聚合 / 素材转码PNG→RGB565   │
│              │ 天气转发(open-meteo)            │
│              └──────────┬─────────────────────┘
│                         │ HTTPS·设备令牌·每小时
│                         ▼
└─ AI Passport 设备固件（本仓库，feature/* 分支）
   Shell 导航 / 仪表盘 / 宠物+番茄 / 设置
   NVS(状态) + LittleFS(素材) + 浅睡计时 + 深睡空闲
```

设备零厂商凭证，只存：Wi-Fi 凭证、服务地址、设备令牌（均可经 SoftAP 配网页写入/重置）。

## 3. 页面与导航

三个一级页循环切换。**键位表（定稿）**：

| 位置 | UP/DOWN 短按 | OK 短按 | OK 长按 |
| --- | --- | --- | --- |
| 仪表盘主界面 | 切换一级页 | 下钻选中项 → 进入详情 | 无 |
| 仪表盘下钻页 | 在三项详情间切换 | — | 返回主界面 |
| 宠物页 | 切换一级页 | 启动/累加番茄计时 | 取消全部计时 |
| 设置页 | 切换一级页 | 进入/调整选项 | 返回/退出选项 |

息屏唤醒后回到息屏前所在页。番茄胜利时无论当前在哪页，自动跳到宠物页播胜利动画+音效后停留。

## 4. 仪表盘

### 4.1 主界面

三张汇总卡（竖排，各占约 1/3 屏），数据来自**主力账户**（配置中心可选，默认 Claude）：

1. **周额度**：百分比大字 + 用量/上限小字 + 重置倒计时（天）
2. **5 小时额度**：百分比 + 当前窗口剩余时间
3. **本周 Token 消耗**：百分比（分母=配置中心设置的周 Token 预算，未设置则显示纯数值）

卡片选中态高亮，OK 下钻。顶部状态条：同步时间（`xx分钟前`）、Wi-Fi 图标、电池。

### 4.2 下钻页

UP/DOWN 在三项详情间切换（不回一级页）。每项详情 = 主力账户该维度的数值明细 + 其余已连接账户同维度横向列表（每家一行：Logo 字样 + 百分比/数值）。长按 OK 返回主界面。

### 4.3 用量快照（服务 → 设备）

```jsonc
{
  "schema": 1,
  "generatedAt": "2026-09-22T06:00:00+08:00",
  "accounts": [{
    "provider": "claude",            // claude|glm|deepseek|chatgpt
    "label": "工作号",
    "quotas": {
      "weekly":      { "used": 62,   "cap": 140, "unit": "h", "resetAt": "..." },
      "rolling5h":   { "used": 18,   "cap": 36,  "unit": "h", "resetAt": "..." },
      "weeklyTokens":{ "used": 412000, "cap": null }   // cap null = 无预算,显示纯数值
    }
  }],
  "weather": {
    "code": 61,                       // WMO code, 归一化为 晴/阴/雨/雪
    "sunrise": "06:12", "sunset": "18:05",
    "city": "上海"
  },
  "assetBundle": { "version": 3 }     // 有新版则设备发起素材下载
}
```

设备端规则：快照整体落 NVS（键值 JSON 串），离线时展示最后已知并标注"离线 x 小时"。百分比一律服务端算好，设备只渲染。

## 5. 宠物

### 5.1 动作与渲染

| 动作 | 触发 | 帧规格 |
| --- | --- | --- |
| 跑步 | 默认态 | 64×64，4–8 帧循环 |
| 打怪 | 番茄计时进行中 | 64×64，4–8 帧循环 |
| 睡觉 | 作息窗口内且无计时 | 64×64，2–4 帧循环 |
| 胜利 | 计时全部结束 | 64×64，一次性播放 1–2s |

地图条带：宽 240 × 高 160，横向匀速滚动、首尾无缝循环；角色固定 x≈屏 1/3，贴地。时段效果用**运行时调色**实现（白天原色 / 傍晚暖色 / 夜间压暗偏蓝，LUT 或 LVGL 样式），天气用小尺寸叠加精灵（雨丝/雪花各 1 组 2–3 帧动画、晴天光斑、阴天无叠加）——**不预烘 12 套地图**。

### 5.2 天气矩阵（4 天气 × 3 时段）

时段由快照内当日日出日落划分：白天=sunrise+30min ~ sunset−60min，傍晚=sunset−60min ~ sunset+45min，其余为夜间（阈值两端留余量，避免闪烁切换，加 10 分钟滞回）。天气由 WMO code 归一化：0–2 晴，3/45/48 阴，51–67/80–82 雨，71–77/85–86 雪。离线沿用最后已知。

### 5.3 头顶 HUD 与底部信息条

- 顶部：`Lv.12` 徽标 + 当前级内进度细条（宽 80px）
- 底部信息条（三项，用户指定）：`今 3 · 周 18 · 下一级 7`（单位番茄）

### 5.4 作息

默认 23:00–次日 8:00 睡觉（停止跑步动画、显示睡觉动作、地图停止滚动），**设备设置页可调**起止时间（±分钟步进 30）。作息窗口内仍允许开番茄钟（宠物熬夜打怪），胜利音效音量跟随设置。

## 6. 番茄计时与经验

### 6.1 状态机

```
IDLE ──OK短按──▶ RUNNING(单元数n=1)
RUNNING ──OK短按且n<5──▶ RUNNING(n+1)      // 每按一次 +25min
RUNNING ──OK短按且n=5──▶ 短促提示音,不变
RUNNING ──OK长按──▶ IDLE(取消,不记经验)
RUNNING ──到时──▶ VICTORY(动画+音效,授经验n) ──▶ IDLE
```

- 计时进行中允许息屏/浅睡（ADR-0003）：状态（绝对结束时间戳、单元数、已授经验数）每次变更写 NVS，掉电重启后按绝对时间重算
- 单元边界（每满 25 分钟）静默 +1 经验；全部结束才播胜利
- 胜利时若在其他页自动跳转宠物页

### 6.2 经验与等级（分段定值，单位=番茄）

| 当前等级 L | 升到 L+1 需（番茄） | 节奏参考（8 番茄/天） |
| --- | --- | --- |
| 1–9 | 5 | 一天升 1.6 级 |
| 10–29 | 15 | 约 2 天 1 级 |
| 30–59 | 25 | 约 3 天 1 级 |
| 60–98 | 50 | 约 6–7 天 1 级 |
| 99 | 100（终局） | 约 12 天 |

满级 100 = 累计 3145 番茄 ≈ 1308 小时专注。等级=分段表反查，纯整数运算；`今日番茄`/`本周番茄`分别于本地 0 点、周一 0 点清零；经验与等级永不清零。全部存 NVS。

## 7. 设置页（设备侧）

| 项 | 形式 |
| --- | --- |
| 亮度 | 5 档循环（LEDC PWM） |
| Wi-Fi | 进入配网流程（SoftAP：设备发热点，手机连上后浏览器填 SSID/密码+服务地址） |
| 自动息屏 | 15s / 30s / 1min / 2min |
| 作息时间 | 起/止各自 ±30min 调整 |
| 连接手机 | 显示服务地址二维码 + 当前令牌状态 |
| 音量 | 0–5 档（胜利音效/提示音） |

## 8. 设备 ↔ 服务协议

- 同步：Wi-Fi 连接成功后立即同步一次，此后每小时一次；手动触发（设置页"立即同步"）
- 拉取：`GET /api/snapshot`，头 `X-Device-Token`；响应即 4.3 快照
- 素材：快照内 `assetBundle.version` 高于本地时，`GET /assets/bundle_v{N}.bin`（manifest+帧数据顺序打包），流式分块写入 LittleFS，写完原子切换、旧版延迟清理
- 时间：设备用 SNTP 对本地服务对时（或服务返回 `generatedAt` 校准），作息/今日/本周重置依赖此时钟

## 9. 本地服务组件

| 组件 | 职责 | P1 实现 |
| --- | --- | --- |
| 采集器 Claude | 周额度/5h 窗口/周 Token | 复用开源方案（ccusage 一类，读 Claude Code 本地用量日志），常驻采集 |
| 采集器 GLM/DeepSeek | 余额/用量 | 官方 API + key（存服务侧） |
| 采集器 ChatGPT | 订阅额度无官方接口 | **P2，待调研** |
| 快照聚合 | 归一化为 4.3 schema | 定时刷新 + 按需 |
| 配置中心 Web | 账户连接/主力账户/城市/Token 预算/素材上传 | 局域网+口令，详见[配置中心设计规格](./2026-09-22-config-portal.md) |
| 素材管线 | PNG→RGB565 帧包 + manifest、尺寸校验 | 服务端 sharp/自写转码 |
| 天气 | open-meteo（免 key，含日出日落） | 缓存 30 分钟 |

## 10. 技术选型

| 领域 | 选择 | 理由 | 被否决 |
| --- | --- | --- | --- |
| 固件框架 | ESP-IDF 5.5.3 + 仓库 BSP | 仓库既定 | Arduino 兼容层 |
| UI | LVGL（BSP 已集成） | 既定；页面切换即建即毁控内存 | — |
| HTTP/TLS | esp_http_client + esp-tls(mbedTLS) | 原生，凭证少 | — |
| JSON | cJSON | IDF 自带、可流式、内存可控 | jsmn（裸解析太底层） |
| 素材存储 | LittleFS（`esp_littlefs`） | 掉电安全、文件语义清晰 | FATFS（磨损与体积劣势） |
| 状态持久化 | NVS | 既定 | — |
| 计时电源 | 浅睡+定时器；空闲深睡 | ADR-0003 | 计时中深睡 |
| 时间 | SNTP 对本地服务 | 离线容忍漂移 | 外部 RTC 芯片（无器件） |
| 提醒 | ES8311 扬声器音效 | **板子无震动马达/蜂鸣器**，唯一下选项 | 震动 |
| 服务端 | Node.js + TypeScript（单进程：Fastify + sharp + 采集器进程管理） | Web/转码/JSON 生态最顺；配中心与管线同仓开发 | Go（亦可，团队熟再换） |
| Claude 采集 | 开源 ccusage 类方案 | 用户指定"找开源方案" | 自写解析 |
| 天气 | open-meteo | 免 key、含日出日落 | 和风等需 key |
| 测试 | 主机侧 unity（仓库既有模式）跑纯逻辑 | 仓库惯例 | — |

## 11. 内存与电源预算（红线）

- TLS 握手峰值约 40–50KB 堆：**同步任务与音频播放不同时进行**；同步期间暂停帧动画加载
- LVGL：页面切换销毁旧屏再建新屏；宠物页为常驻页但控件数固定且少
- 素材下载：分块 4KB 流式写 LittleFS，绝不整包进 RAM
- 浅睡（计时中）电流百微安级；深睡（空闲）微安级，按键唤醒

## 12. 测试与验收

主机侧单测（纯逻辑，不碰硬件）：番茄状态机（堆叠/取消/掉电重算/跨单元授经验）、分段经验表与今日/本周重置、天气归一化与时段滞回、快照解析与离线标注。

真机验收（P1 出厂前逐项）：三页导航与键位表全路径；下钻与返回；25/50/125 分钟计时息屏不断、到点跳页+音效；作息睡觉/唤醒表现；12 种天气×时段组合目检；SoftAP 配网全流程；离线 24 小时快照标注；素材包 v1→v2 热更新；深睡一夜掉电水平；满级曲线抽查（写 NVS 伪造经验值验证显示）。

## 13. 里程碑

- **P1（能天天戴）**：壳+导航、仪表盘（本地服务+Claude/GLM/DeepSeek 采集器）、宠物三动作+AI 占位素材+番茄计时+经验等级+浅睡续跑、天气 12 组合（日出日落）、胜利音效、设备设置全项、SoftAP 配网、每小时同步、配置中心最小版（账户连接+主力账户+城市）
- **P2**：素材自定义全链路（上传/转码/热更新/装扮元素配置）、ChatGPT 采集器（视可行性）、下钻页 7 天迷你柱状图
- **P3（可选）**：多设备、装扮元素数量/密度配置、更多动作

## 14. 风险与待确认假设

1. **ChatGPT 订阅额度采集无官方接口**（P2，可能降级为 API 用量口径或砍掉）
2. **GLM Coding Plan 额度口径**需在服务端调研确认（有无官方/可推导口径）
3. **UI 语言默认中文**——需内嵌字体子集（约 100–200KB Flash，已计入 3MB 固件预算）；如要英文可零成本切换，**此项待你最终确认**
4. ccusage 类开源方案随 Claude Code 本地格式演进可能失效，采集器插件化隔离影响
5. 深睡期间 RTC 漂移：靠每次同步对时纠偏，长期离线时作息窗口可能偏移（可接受）
