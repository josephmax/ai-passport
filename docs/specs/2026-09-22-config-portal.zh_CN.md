# 配置中心设计规格

- 原日期：2026-09-22；目标更新：2026-10-14
- 状态：旧局域网配置中心部分已实现；BLE 伴侣适配接口已实现，设备验收待完成
- 权威规格：[BLE 伴侣 MVP](2026-10-14-ble-companion-mvp.zh_CN.md)、[ADR 0006](../adr/0006-ble-companion-without-device-networking.zh_CN.md)
- 相关：[应用规格](2026-09-22-multi-pendant-app.zh_CN.md)、[接入及历史交接](2026-09-24-badge-onboarding.zh_CN.md)、[术语](../CONTEXT.zh_CN.md)

## 1. 当前目标：三个配置面

| 配置面 | 托管者 | 职责 |
| --- | --- | --- |
| 电脑伴侣连接面 | 电脑与设备确认 | BLE 发现、认证绑定、重连、忘记／吊销、麦克风状态 |
| 设备设置 | 挂坠三键 UI | 本地设置、连接／忘记电脑、立即同步、麦克风模式 |
| 配置中心 | 本地服务，主机浏览器 | 名牌、账户、偏好、设备、素材；保留校验和供应商凭证归属 |

不要求设备配网表单或手机。设备保留电脑绑定、本地设置、番茄／经验、最后快照及已安装素材。迁移时旧网络配置先不启用，不擦除 NVS。当前配置中心已有上述五个页签；总览／实时预览及完整原生配置 UI 延后。

## 2. 绑定与设备管理

挂坠打开**连接电脑**，Mac 辅助程序选择设备，两端确认认证 BLE 数字比较，bond、协商能力并下发最新快照／时间。只对已授权关联自动重连。忘记／换绑须明确确认并保留本地应用数据。完整身份、配对窗口和失败规则见 BLE 规格。

用绑定电脑／设备身份、BLE 连接状态、快照年龄及明确的忘记／吊销替换网络配对码／令牌接入。BLE bond 不是 HTTP 服务令牌；仅吊销旧令牌不能吊销 BLE 连接。注册表已按电脑 UUID 与出厂 MAC 隔离，完整多设备交互后续实现。BLE 数字比较与旧六位服务配对码不同。

## 3. 服务 API 边界与变更下发

保留采集器、schema-1 快照、名牌／设置校验、PNG 转码和 APB1 发布。原生辅助程序先在主机回环复用鉴权快照访问，HTTP 凭证留在电脑。挂坠交换有界 BLE 消息，不做 HTTP-over-BLE 请求。旧代码仍有 `/api/pair`、`/api/snapshot` 和 `/assets/*`，不证明 BLE 已实现。

| 变更 | 下一版设备生效方式 |
| --- | --- |
| 绑定／重连 | 最新有效快照和新生成的主机时间 |
| 采集成功或账户／偏好／名牌修改 | 已连接伴侣下发新快照 |
| 手动立即同步 | 请求最新下发，区分采集新鲜度和传输成功 |
| 本地亮度／音量／作息 | 本地即时生效 |
| 新素材包 | 发布保留，设备下发延后至 BLE 素材能力实现 |

主机采集／缓存计划独立。手动下发不能刷新旧读数的采集时间。麦克风模式合并快照，延后至采集停止再应用／持久化。离线保留最后有效值和年龄。不支持的素材更新不能阻塞快照或反复尝试不存在的传输。

## 4. 部署与安全

- 供应商凭证和配置中心口令留在主机。设备 BLE 绑定授权受保护数据／音频访问，广播不包含凭证。
- 下一版默认使用主机回环和现有口令会话。当前代码仍默认 `0.0.0.0`，实施时须明确配置回环，不能声称文档已改变监听行为。可选手机／局域网访问属于以后独立部署选择。
- 当前 API Key 是受主机权限保护的明文本地文件；BLE 迁移本身不加密这些文件，也不改变读数覆盖范围。
- 吊销须断开／废止活动 BLE 关联并停止音频。旧服务配对码仍单次使用、10 分钟过期，但不是下一版绑定协议。
- 保留服务端素材大小／帧数校验。后续 BLE APB1 下发须保留暂存写入、完整校验和原子切换。

## 5. 下一步与替代记录

按 [BLE MVP](2026-10-14-ble-companion-mvp.zh_CN.md) 的 M0 虚拟麦克风兼容、M1 BLE 绑定／数据、M2 麦克风、M3 组合验收实施。复用现有配置页和发布。NFC／手机接入、原生应用打包、预览、多设备及 BLE 素材下发延后。

原设计要求设备 SoftAP 表单、手机切网、Wi-Fi／服务地址输入、服务配对码和每小时 HTTP 轮询。办公网可能拒绝挂坠，而附近电脑可提供 BLE，因此这些已取代。供应商凭证留在主机、来源覆盖、配置校验及主机转码继续有效。当前旧固件仍执行历史流程，新实现须通过迁移／真机验收才能声称无需配网运行。

### 1. 三个配置面（职责边界）

| 配置面 | 托管者 | 管什么 |
| --- | --- | --- |
| SoftAP 配网页 | **设备**（captive portal 迷你页） | 新设备入网三要素：Wi-Fi 凭证、服务地址、一次性配对码 |
| 设备设置页 | 设备（三按键 UI） | 亮度、音量、自动息屏、作息时间、立即同步、显示配对二维码 |
| 配置中心 | **本地服务**（Web，手机浏览器） | 账户连接、主力账户、城市、Token 预算、素材全链路、设备与令牌管理 |

原则：厂商凭证和配置中心设置留在服务端。设备持久化 Wi-Fi／服务地址／令牌、本机设置、番茄／经验记录及素材包；用量和名牌设置随快照下发。

### 2. 原始目标信息架构

本节保留最初目标，并非当前导航。已实现的页签为**名牌、账户、偏好、设备、素材**；总览及其与设备一致的快照预览尚未实现。现行设计与实现矩阵见[名牌与接入设计](./2026-09-24-badge-onboarding.zh_CN.md)。

#### 2.1 总览
- 设备卡 × N：在线状态、最后同步时间、电量、固件版本、当前皮肤包版本
- 快照预览：渲染当前快照在设备上的样子（与设备所见一致）

#### 2.2 账户
- 四家账户卡：
  - **Claude**：采集器运行状态、最近采集时间、日志入口（采集器凭证留在采集侧配置）
  - **GLM / DeepSeek**：API key 表单（目前以明文保存在本机权限 0600 的文件，回显仅尾 4 位）
  - **ChatGPT**：P2 占位，说明无官方接口
- 每家卡的额度实时预览（周额度/5h/Token，无该维度则隐藏）
- 底部：**主力账户**单选（决定设备仪表盘主界面三项）

#### 2.3 素材（P1 = 上传+校验+静态缩略图；动画预览 P2）
- **动作**：四个槽位——跑步 / 打怪 / 睡觉 / 胜利。每槽：上传 PNG 帧序列（服务端转 RGB565）、设帧率（1–10fps）、静态缩略图宫格
- **地图**：上传条带 PNG（转码后 240×160 RGB565），静态首尾拼接预览
- **装扮**：元素库（上传 24×24 元素）、每元素启用开关、同屏数量 1–2
- **皮肤包版本管理**：草稿集 → 「发布」生成新版本号 → 设备下次同步下载；历史版本列表 + 一键回滚（回滚=再发布旧版本号）

#### 2.4 偏好
- 城市（搜索选择，用于天气与日出日落）
- 周 Token 预算（null = 设备显示纯数值不加百分比）

#### 2.5 设备
- 设备列表：名称、令牌状态、最后同步
- **生成一次性配对码**（6 位数字，10 分钟有效，单次使用）
- 令牌吊销（吊销后设备下次同步失败，回到待配对态）
- 每台设备的"当前皮肤包版本"与强制重下发

### 3. 配对与配网流程（新设备开箱）

1. 当前固件需在设备设置中选择 Wi-Fi 才进入 SoftAP 模式，屏幕显示热点名（`Passport-XXXX`）；最初设想的首次开机自动进入尚未实现。
2. 手机连接该热点 → 打开设备托管的配网页；是否自动弹出取决于手机，尚未真机验证。
3. 表单四项：Wi-Fi SSID／密码／服务地址／一次性配对码（配置中心·设备页生成）
4. 设备保存 → 连接 Wi-Fi → `POST /api/pair {code, deviceName}` → 服务校验配对码 → 下发**设备令牌**
5. 绑定完成；设备开始每小时同步，配置中心设备列表记录上次请求时间。

配对码一次性 + 短时效；令牌可吊销重发（重新走配网流程）。

### 4. API 草案

| 端点 | 方向 | 说明 |
| --- | --- | --- |
| `POST /api/pair` | 设备→服务 | 配对码换设备令牌 |
| `GET /api/snapshot` | 设备→服务 | 头 `X-Device-Token`；快照 JSON（见主规格 §4.3），含 `assetBundle.version` |
| `GET /assets/bundle_v{N}.bin` | 设备→服务 | 皮肤包（manifest+帧数据顺序打包），流式分块写 LittleFS |
| `/portal/...` | 浏览器→服务 | 名牌、账户、偏好、素材、设备的鉴权 HTML 页面和表单提交 |

配置中心使用口令会话鉴权，应部署在可信局域网。素材上传走 multipart，服务端校验尺寸/帧数并转码。

### 5. 变更生效时效（定稿：每小时 + 手动）

| 变更 | 设备可见时机 |
| --- | --- |
| 主力账户 / 城市 / Token 预算 | 下次快照（≤1 小时），或设备"立即同步" |
| 账户连接增删 | 同上（影响快照内容） |
| 素材发布新版本 | 下次同步发现 `assetBundle.version` 变化 → 下载 → 原子切换 |
| 设备本机设置（亮度等） | 即时（不经服务） |

### 6. 安全清单

- 厂商凭证和配置中心口令留在服务主机；设备保存自身令牌、Wi-Fi 凭证与服务地址。API Key 目前以明文存在服务数据目录，仅受主机文件权限保护。
- 令牌吊销即刻生效（下次同步被拒）
- 配对码一次性、10 分钟过期
- 配置中心只应部署在可信局域网。服务目前默认监听 `0.0.0.0`，须由主机控制网络暴露范围，不能把“仅局域网”当作程序自动保证。
- 素材包服务端校验：尺寸/帧数/包体上限（防塞爆 5MB LittleFS）

### 7. 切分

- **P1**：账户页（Claude/GLM/DeepSeek）+ 主力账户、偏好页、设备页（配对码/吊销）、名牌页、素材上传+校验+静态预览+发布/回滚、SoftAP 配网页、`/api/pair`
- **P2**：动画预览（按帧率播放、地图滚动+装扮叠加）、ChatGPT 采集卡、快照预览渲染
- **P3+**：多设备分组、远程访问方案、素材分享
