# AI Passport Multi-Pendant

A single-firmware application running on the FoloToy AI Passport wearable: an
LLM usage dashboard, a pet-skinned Pomodoro timer, system settings, and a
phone-side account and asset configuration hub.

## Language

### Navigation and pages

**Home**:
The device's single top-level screen: the pet scene stays resident, function
entries are picked with the cursor; boot lands here, and a long press returns
here from any second-level list.
_Avoid_: top page, main menu, home screen, tab

**Second-level List**:
The umbrella term for full-screen lists entered from Home: the usage list
(quota-kind summaries, drillable) and the settings list (option adjustment
and flow-page entries).
_Avoid_: second-level menu, sub-menu

**Drill-down**:
A secondary detail page for one quota kind, entered from the usage list, with
a way back.
_Avoid_: detail popup

### Dashboard domain

**Coding Account**:
A personal account on one LLM service (Claude, GLM, DeepSeek, ChatGPT, ...)
whose quota and usage the dashboard tracks. Credentials live only in the
config portal and never reach the device.
_Avoid_: API key, provider, login

**Quota Kind**:
One measurable limit dimension. MVP ships three: weekly quota, rolling
5-hour quota, weekly token consumption.
_Avoid_: metric, quota type

**Usage Snapshot**:
A one-shot capture of all quota-kind readings at a point in time, aggregated
by the local service and pulled by the device for display.
_Avoid_: usage data, report

**Today Spend**:
The sum of token consumption across all connected Coding accounts since
local midnight, aggregated by the local service and delivered with the
snapshot; shown as the Home headline.
_Avoid_: daily burn, today's usage

### Pet domain

**Action**:
One configurable looping animation of the pet plus its meaning. Three fixed
actions: Run (default), Fight (while a focus block runs), Sleep (inside the
rest window).
_Avoid_: state, pose, expression

**Map Skin**:
The horizontally scrolling backdrop behind the pet, fixed height, seamlessly
loopable end to end.
_Avoid_: background, scene, level

**Asset Bundle**:
A complete published asset set for the device (all action frames + map skin +
decorations + manifest), versioned as a whole and switched atomically by
version on the device.
_Avoid_: asset pack, resource pack, theme

**Decoration**:
Small ornaments that appear at random positions on the map and rotate
periodically; their art is configurable, 1–2 on screen.
_Avoid_: obstacle, pickup, NPC

**Focus Block**:
One 25-minute countdown unit. The count (1–5) is preset on the Home focus
indicator; confirming restarts a whole countdown of that total length. Each
completed unit grants 1 XP, none for a cancelled one.
_Avoid_: Pomodoro (fine colloquially; documents use Focus Block), focus session

**XP**:
The pet's growth points, measured in completed focus blocks; 1 point per
completed unit, none for a cancelled one.
_Avoid_: points, growth value

**Level**:
A milestone mapping over XP with a cap of 100; level-up costs are fixed per
level band (a few blocks per level early on, dozens later); reaching the cap
costs 3145 blocks in total.
_Avoid_: rank, stage

**Today Count**:
Focus blocks completed since local midnight.
_Avoid_: daily count, today's sessions

**Week Count**:
Focus blocks completed since Monday 00:00 local.
_Avoid_: weekly counter

**Rest Window**:
The daily period in which the pet sleeps and stops running (bounds in the
development spec; default 23:00–08:00 next day).
_Avoid_: sleep time, night mode

**Weather Effect**:
The map overlay look produced by crossing weather (clear, overcast, rain,
snow) with time of day (day, dusk, night): 12 combinations.
_Avoid_: weather skin, ambience

### System domain

**Pairing Code**:
A one-time, short-lived numeric code generated by the config portal; the
device redeems it for a device token during SoftAP provisioning.
_Avoid_: activation code, binding code

**Config Portal**:
The web configuration pages hosted on the local service and opened from a
phone browser; manages Coding account connections and pet asset uploads.
_Avoid_: phone app, mobile client

**Local Service**:
A lightweight self-hosted backend on the user's own machine/NAS: reuses open
source collectors to gather each Coding account's quota, aggregates usage
snapshots, hosts the config portal, and distributes asset bundles and
weather. The device talks only to it, once per hour.
_Avoid_: proxy, backend, server, gateway
