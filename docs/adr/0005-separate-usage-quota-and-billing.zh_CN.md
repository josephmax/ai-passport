# 0005 — 分开记录本地 Token 用量、订阅额度与 API 账单

ccusage 读取受支持的本地 Agent 记录，提供 Token 计数和估算费用，但这些记录不能证明订阅剩余额度或账户实际账单。继续将 ccusage 用作本地日志适配器，并分别增加供应商额度定时采样、官方账单／余额 API、以及可用时的逐请求 API 用量回执适配器。每条读数都须保留账户、已知的 Agent、指标及单位、统计区间、采集时间、来源，以及官方、观测或估算口径。只有身份与单位允许时本地服务才合并读数；无法取得的读数保持不可用。人民币余额不能放进 Token 字段，请求次数不能标成 Token，估算费用不能标成实际支出。

本地服务按独立计划轮询额度接口，并在时效限制内保留最后一次成功采样；设备每小时拉取不触发供应商轮询。逐请求回执可以计量直连 API 的 Token 用量，官方账单或余额则是单独的金额读数。本地 Agent 日志和请求回执可能描述同一次调用，因此相加前须用稳定请求标识去重。若来源无法提供账户全量，就展示其观测覆盖范围，不声称数据完整。本决策延续 [ADR 0001](0001-usage-proxy-holds-credentials.zh_CN.md) 的本地服务凭证边界，并修正其中余额 API 可提供 Token 消耗的暗示。
