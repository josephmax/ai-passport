# AI Passport 多合一挂坠（Multi-Pendant）

在 FoloToy AI Passport 可穿戴设备上运行的单一固件应用：LLM 用量仪表盘、以宠物为外壳的番茄钟、系统设置，以及手机侧的账户与素材配置中心。

## Language

### 导航与页面

**主屏（Home）**：
设备唯一的一级界面：宠物场景常驻，各功能入口经光标选取；开机直达，从二级列表长按逐级返回至此。
_Avoid_: 一级页、主菜单、桌面、Tab

**二级列表（Second-level List）**：
从主屏进入的全屏列表的统称：用量列表（额度维度汇总，可下钻）与设置列表（选项调整与流程页入口）。
_Avoid_: 二级菜单、子菜单

**下钻（Drill-down）**：
从用量列表进入某一项额度维度的详情页，带返回。
_Avoid_: 详情弹窗

### 仪表盘域

**Coding 账户（Coding Account）**：
一个 LLM 服务的个人账户（Claude、GLM、DeepSeek、ChatGPT 等），其额度与用量被仪表盘追踪。凭证只存在于配置中心，永不进入设备。
_Avoid_: API key、服务商、账号

**额度维度（Quota Kind）**：
一种可度量的限额口径。MVP 三项：周额度、5 小时额度、本周 Token 消耗。
_Avoid_: 指标、配额类型

**用量快照（Usage Snapshot）**：
某时刻全部额度维度读数的一次性采集结果，由配置中心聚合生成、设备拉取展示。
_Avoid_: 用量数据、报表

**今日消耗（Today Spend）**：
主屏沿用的名称，表示本地零点起观测到的 Token 消耗；它不是货币收费，也不代表供应商账单全量。
_Avoid_: 实际支出、账单总额

**用量读数（Usage Reading）**：
针对某一 Coding 账户及指标、在明确区间内取得的有来源读数；其单位、采集时间和覆盖范围与数值一同保存。
_Avoid_: 可互换的额度、笼统用量数

**订阅额度（Subscription Quota）**：
供应商定义的重置窗口内限额或剩余容量，单位可能是请求次数或百分比，而非 Token。
_Avoid_: Token 消耗、API 余额

**API 实际费用（API Charge）**：
供应商报告的按量 API 货币收费，与估算费用及预付余额分开。
_Avoid_: Token 用量、余额、估算费用

### 宠物域

**动作（Action）**：
宠物的一段可配置循环动画及语义。固定三种：跑步（默认）、打怪（番茄计时中）、睡觉（作息窗口内）。
_Avoid_: 状态、姿态、表情

**地图皮肤（Map Skin）**：
宠物身后的横向滚动背景，高度固定、首尾可循环拼接。
_Avoid_: 背景、场景、关卡

**皮肤包（Asset Bundle）**：
一次发布到设备的完整素材集合（全部动作帧 + 地图皮肤 + 装扮元素 + 清单），整体版本化，设备按版本原子切换。
_Avoid_: 素材包、资源包、主题

**装扮元素（Decoration）**：
地图上随机出现、周期轮换的小型点缀物，素材可配置，同屏 1–2 个。
_Avoid_: 障碍物、道具、NPC

**番茄计时（Focus Block）**：
一次 25 分钟的倒计时单元。数量在主屏番茄指示条上预设（1–5 个），确认后按总时长重新倒计时；每完成一个单元获得 1 点经验，取消不获得。
_Avoid_: 番茄钟（口语可，文档统一用番茄计时）、专注会话

**经验（XP）**：
宠物成长的点数，单位即番茄数；每完成一个番茄计时单元获得 1 点，取消不获得。
_Avoid_: 积分、成长值

**等级（Level）**：
经验的里程碑映射，上限 100；升级花费按等级分段定值（前期每级数个番茄、后期每级数十个），满级合计 3145 番茄。
_Avoid_: 段位、阶段

**今日番茄（Today Count）**：
当日零点起完成的番茄计时单元数。
_Avoid_: 今日次数、日计数

**本周番茄（Week Count）**：
本周（周一零点起）完成的番茄计时单元数。
_Avoid_: 周计数

**作息窗口（Rest Window）**：
每日宠物睡觉、停止跑步的时间段（起止时间见开发文档；默认 23:00–次日 8:00）。
_Avoid_: 睡觉时间、夜间模式

**天气效果（Weather Effect）**：
天气（晴、阴、雨、雪）与时段（白天、傍晚、晚上）叉乘出的地图叠加表现，共 12 种组合。
_Avoid_: 天气皮肤、氛围

### 系统域

**配对码（Pairing Code）**：
配置中心生成的一次性短时效数字码，设备凭它在 SoftAP 配网时向本地服务换取设备令牌。
_Avoid_: 激活码、绑定码

**配置中心（Config Portal）**：
手机浏览器访问的 Web 配置页，托管在本地服务上；管理 Coding 账户连接与宠物素材上传。
_Avoid_: 手机端、App、设置端

**本地服务（Local Service）**：
自托管在用户自己机器/NAS 上的轻量后端：基于开源方案采集各家 Coding 账户额度、聚合为用量快照、托管配置中心、分发素材包与天气。设备只与它通信，每小时拉取一次。
_Avoid_: 代理、后端、服务器、网关
